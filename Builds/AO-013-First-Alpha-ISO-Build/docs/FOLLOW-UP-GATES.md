# Folge-Gates

Ein AO-013-Build-Antrag ist keine ISO und keine Ausführungsfreigabe. Für die erste Alpha-ISO sind anschließend der überprüfte Container-Recipe, die getrennte Owner-Freigabe der rootless Podman-Ausführung, ISO-Hash/Provenance, VM-UEFI/Secure-Boot-Tests und eine reale Hardwareabnahme erforderlich.

AO-013 erzeugt, importiert oder registriert keine Schlüssel und schreibt keine Firmware oder Datenträger.
