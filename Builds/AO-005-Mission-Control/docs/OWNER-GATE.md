# Owner Gate

Mission Control defaults to deny when no Owner-Gate adapter is supplied. Every action name and rationale must be non-empty, bounded text; payloads are not accepted, preventing Mission Control from becoming a general command transport or secret container.

The AO-005 module never runs a proposed action. Production integration still requires the canonical AIDRAX Owner-Gate decision, an approved action contract, an authorized executor, HERMES audit events, and ARGUS health evidence.
