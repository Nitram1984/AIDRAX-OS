# Provider Contract 1.0.0

**Classification:** Public boundary, reserved  
**Stability:** Stable

CA-013 defines no provider integration surface. The package has no provider dependency, network provider configuration, provider registry, Serus integration, AGY integration or Codex runtime.

The compatibility guarantee is absence: importing and using the CA-013 public APIs does not require an external AI provider. A provider contract may only be added in a later approved build.
