# Security Policy

## Project status

AIDRAX OS is in closed alpha. There are no supported stable releases or guaranteed security-maintenance periods at this stage. Reports concerning the current development state are welcome. Do not rely on an alpha build for production or sensitive workloads.

## Report a vulnerability privately

Use [GitHub private vulnerability reporting](https://github.com/Nitram1984/AIDRAX-OS/security/advisories/new), or open the repository's **Security** tab and choose **Report a vulnerability**.

Do not disclose vulnerability details in a public issue, discussion, or pull request. If the private reporting option is unavailable, open a general issue asking the maintainer to enable a private reporting channel, without including technical details.

Include:

- The affected branch, commit, or version.
- A description of the vulnerability and its potential impact.
- Minimal reproduction steps or a proof of concept using synthetic data.
- Relevant environment details and possible mitigations.

Remove credentials, tokens, personal information, and unrelated private data. Only test systems you are authorized to test.

## Handling reports

The maintainer reviews reports and coordinates follow-up through the private advisory. Additional information may be requested to reproduce the issue. Response and remediation times are not guaranteed during the alpha stage.

Please coordinate public disclosure with the maintainer so that affected users can receive useful guidance and, where possible, a fix.
